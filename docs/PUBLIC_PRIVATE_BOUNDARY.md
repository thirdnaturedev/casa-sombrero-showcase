# Public / Private Project Boundary

Casa Sombrero uses separate repositories for public presentation and production development.

## Public

This repository may contain:

- project description
- feature overview
- screenshots
- high-level architecture
- design principles
- technology stack
- selected non-sensitive demonstrations
- portfolio material

## Private

The production repository contains information intentionally excluded from this public showcase, including:

- complete application source
- complete route implementation
- ordering internals
- reservation internals
- state-management implementation
- complete asset collection
- production configuration
- environment configuration
- deployment internals
- future API integrations
- future authentication logic
- future payment integrations
- private security documentation
- internal development documentation

## Important

The public repository is not intended to be a buildable copy of the production website.

It exists to demonstrate the project's design, engineering approach, and completed functionality without distributing the complete proprietary application.
