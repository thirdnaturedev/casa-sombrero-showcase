# Casa Sombrero — Feature Overview

## Desktop Experience

The Casa Sombrero desktop website uses an immersive single-scene presentation.

Major experiences include:

- Hero presentation
- Main Dishes
- Starters
- Chef's Special
- Chef Sauces
- Drinks
- Reservation
- About
- Interactive food presentation
- Animated scene transitions

The interface is intentionally different from a conventional vertically scrolling restaurant website.

## Mobile Ordering

The mobile experience provides dedicated ordering flows.

### Dine In

Customers can:

- enter the dine-in experience
- browse menu categories
- add dishes
- adjust quantities
- review their cart
- maintain a table-specific order

### Delivery

Customers can:

- enter the delivery experience
- browse dishes
- build a cart
- enter delivery information
- review applicable charges
- review their order before confirmation

## Responsive Entry

A single root website address supports both experiences.

Large screens display the immersive desktop experience.

Small screens display the mobile ordering experience.

## Reservation

The desktop experience includes an interactive reservation journey covering:

- experience selection
- date
- time
- guest count
- seating preferences
- occasion
- customer details
- dietary preferences
- special requests
- confirmation

## Current Scope

The showcased release focuses on the frontend experience.

Production authentication, payment processing, administration systems, and backend infrastructure are intentionally outside the showcased implementation.
